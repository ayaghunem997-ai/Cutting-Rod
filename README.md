# Rod Cutting Problem

This project provides a clean and beginner-friendly TypeScript solution for the Rod Cutting Problem using Dynamic Programming. 

The program calculates the maximum profit that can be obtained by cutting a rod into smaller pieces and selling them based on a given price array, where each index represents the price of a piece with that length.

The solution uses a bottom-up DP approach to avoid repeated calculations and improve performance. 

The code is written with simplicity and readability in mind, follows TypeScript standards, avoids unnecessary complexity, and is designed to help beginners understand the core idea behind Dynamic Programming and optimization problems.
